Загрузите базы знаний

Выберите один или несколько файлов kb_*.sqlite, подготовленных на компьютере (скрипт make_kb.py): по одному файлу на группу документов. Файлы сохранятся в памяти приложения, после этого поиск работает без интернета. Повторная загрузка файла той же группы заменяет её.


    


    

      
В каких документах искать

      
      

      

    


    

      
Словарь синонимов

      
Слова, которые в ваших документах означают одно и то же. Одна группа на строку, слова через «=». Пример: captain = pic = pilot in command. Работает сразу, без интернета; строки с # игнорируются.

      
      

      
Встроенные группы

      
Уже работают, менять не нужно. Свои строки добавляются к ним.
